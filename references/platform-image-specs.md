## 十二、统一母版与导出要求

### 国内图片

| 项目 | 资料要求 |
|---|---|
| 色彩模式 | RGB，不用 CMYK |
| 分辨率 | 页面图片 72 DPI 已足够 |
| JPG 质量 | 建议 80%-85%；详情页示例约 80% |
| 常见目标大小 | 200-500 KB；仍不得超过各平台单项上限 |
| PNG | 适合透明背景、白底抠图等需要无损 / 透明的素材；文件通常更大 |
| WebP | 部分平台详情页可用；资料称通常比 JPG 小约 30%，但兼容性并非处处一致 |

### 跨境图片

| 项目 | 资料要求 |
|---|---|
| 原始母版 | 至少 3000 x 3000 px、300 DPI、无损 TIFF 或 PNG |
| 原始角度 | 建议准备 5-8 张不同角度和场景原图 |
| 抠图资产 | 先获取透明底 PNG，再派生白底、浅色底、场景和品牌背景 |
| JPG 质量 | 建议 85%-90% |
| Amazon 工作输出 | 2000 x 2000 px |
| eBay 工作输出 | 1600 x 1600 px |
| Etsy 工作输出 | 2700 x 2025 px；正方形版本另用 2000 x 2000 px |
| Shopify 工作输出 | 2048 x 2048 px |
| AliExpress 工作输出 | 1500 x 1500 px |

## 十三、生成和交付硬校验

1. 所有平台版本从同一份已确认产品母版派生，不为每个平台重新创造不同商品。
2. 检查产品结构、颜色、Logo、包装文字、材质外观、配件数量和 SKU 是否与参考图一致。
3. 不得把图片观察升级为容量、材料、性能、认证、兼容或功效证明。
4. 检查背景、主体占比、裁切、分辨率、比例、格式和实际字节数。
5. 每张图记录：平台、用途、尺寸、比例、格式、实际文件大小、来源、生成模型 / 工具和人工复核状态。
6. 图片接口成功只表示生成完成，不表示产品保真或平台合格；结构变化、文字变化或背景不符合时必须判失败。
7. 不把相同成品图不加调整地上传到所有平台；相同母版可以复用，最终构图必须按平台用途派生。
8. 检查移动端裁切和小屏文字可读性。两篇资料没有提供统一文字安全区时，明确写 `资料未列出`。
9. 视频尺寸、时长或编码未列出时，不根据其他平台猜补，正式制作前查看当前后台。
10. 平台自动压缩不替代上传前检查；Shopify 即使会自动生成设备尺寸，也要先检查原图和主题裁切。
