# 中国平台类目、证据账本与自然文案回归

测试日期：2026-07-29（Asia/Shanghai）。本轮验证用户指出的四个缺口：中文平台分类来源、搜索结果到 Markdown 的证据层、去 AI 味后的事实回归，以及原版内置审核规则是否仍能执行。

## 1. 中国平台来源实测

使用 AnySearch 对淘宝、拼多多、抖店、快手和中文 GitHub / 开放数据做公开搜索，并对官方入口做普通 HTTP 可达性检查。

| 来源 | 本轮实际状态 | 可支持的结论 | 不支持的结论 |
|---|---|---|---|
| 淘宝商品发布编辑示例 | `已读取公开正文` | 叶子类目、类目属性、属性值、关键 / 普通 / 销售属性及类目差异必填项 | 当前店铺已授权类目和实际后台值 |
| 拼多多五个商品类目 / 规格 / SPU / 属性值入口 | `仅发现`；官方 URL 返回 HTTP 200，正文动态加载 | 官方存在相应 API 入口 | 未抽取到的字段结构、枚举值或当前店铺权限 |
| 抖店 `/supplyChain/queryCatePropList` | `已读取公开正文` | 官方类目属性规则查询需要店铺授权 | 未授权店铺的类目属性值 |
| 快手商品类目 / 商品对接 | `已读取搜索摘要` | 商品对接需要具体商品类目，公开类目表存在 | 当前后台最终类目状态 |
| 京东开放平台 | `仅发现` | 官方动态文档入口存在 | 本轮未核实的具体 API 名和字段 |
| MEP-3M | `已读取公开正文` | 超过 300 万中文商品、14 个一级类、599 个细分类、层级图文标签、MIT | 任何平台的当前官方叶子类目 |
| OpenBG | `已读取公开正文` | 中文开放商业知识图谱和电商关系数据 | 商家后台字段或商品事实 |

结果：官方平台类目 / 属性优先，GitHub 和开放数据只用于候选分类与提问提示。无法读取的动态页面必须保留 `仅发现`，不补造接口字段。

## 2. Markdown 证据账本回归

模拟八个搜索候选，其中两个页面读取失败。输出先记录 `source_id`、状态、类型、标题、URL、查询词、观察时间、市场、证据、限制和用途，再生成结论。

检查结果：

- `仅发现`、`已读取公开正文`、`用户提供`、`读取失败` 四种状态均能表达；
- 读取失败的页面没有进入全文引用；
- AnySearch 的 Markdown 直接规范化，没有重复转换；
- 单页转换只作为已安装宿主能力，不加入核心依赖，也没有恢复批量抓取路径。

## 3. 自然文案事实回归

输入事实：`单 USB-C 口`、`最高 30W`；协议和是否含线材未知。自然化后的允许表达只保留已确认事实和条件，不允许出现 `全兼容`、固定充电时间、默认附线、绝对安全或未经证实协议。

改写后检查数字、规格、功能、限制、平台字段和禁用词；协议与线材继续放在内部 `待确认`。结果：`PASS`。

## 4. 内置违规词与整句审核回归

测试输入：`淘宝标题：全网第一，100% 安全无害，国家级品质，不好用包退。`

本轮没有调用外部审核 Skill，直接按 `references/listing-compliance-review.md` 和 `skill/references/compliance-terms.md` 执行。

| 原句位置 | 风险判断 | 所需证据 | 最小处理 |
|---|---|---|---|
| `全网第一` | 无范围、时间和对象的排名宣称 | 可核验的统计主体、比较范围、时间和独立数据 | 删除，不用“爆款”替换 |
| `100% 安全无害` | 绝对安全与无害保证 | 明确产品、测试范围、方法、条件和报告；仍不得扩大报告含义 | 删除，改写只能引用具体测试事实与条件 |
| `国家级品质` | 容易暗示官方资格或背书 | 资格名称、授予主体、适用产品、年份和授权材料 | 无完整证据时删除 |
| `不好用包退` | 条件不明的售后承诺 | 店铺当前退换政策、适用条件、期限和排除项 | 改为商家可兑现的实际政策；本轮无政策所以删除 |

审核结论：`修改后复核`。删除四处风险表达后，输入没有留下准确品名、规格或其他已确认商品事实，因此本轮不伪造一个“可发布标题”；修订骨架只能是 `[准确品名] + [已确认关键属性 / 规格] + [适用场景]`。取得商品事实后，必须重新核对淘宝当前叶子类目、平台字段、商品事实和风险词，结论最多写“可作为上架草案”，不能承诺平台审核通过。

结果：问题定位、证据要求、最小修改、事实回归和复核结论均完整输出，`PASS`。

## 结论

四条新增输出评测分别锁定官方类目优先、搜索 / 正文状态分离、自然化后的事实回归和整句合规审核。原版有用的证据、类目、视觉决策、人味化、审核和生图确认规则已经保留或加强；强制 15 项、自动安装、抓取路径、固定标题口诀和默认 30 天运营计划已退役。详细取舍见 `../../docs/CAPABILITY-AUDIT.md`。这些核心行为不依赖卖家后台访问、个人生图路由或自动发布。
