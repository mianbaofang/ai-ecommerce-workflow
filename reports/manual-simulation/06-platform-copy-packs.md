# Four-Platform Copy Test: 420 ml Coffee Cup

Status: superseded early test, not published. This file predates the category-copy framework and leaves too many internal QA caveats inside buyer-facing paragraphs. Do not use it as the current output example. The replacement regression is `09-category-copy-regression.md`, governed by `references/product-copy-framework.md`.

The only confirmed product facts in this historical run were: 420 ml capacity, matte white color, flip lid, no brand, intended for commuting. Material, insulation, dishwasher safety, temperature range, leak performance, cup-holder fit and certifications remain unknown.

### Buyer-facing copy

早上带一杯咖啡出门，420 ml 不会显得太小，也不会把杯子做得过分笨重。这款杯子是哑光白色，配翻盖，放在办公室或通勤路上都比较利落。

目前能确认的就是容量、颜色和翻盖结构。材质、耐温、保温时间、能不能进洗碗机，以及放进包里是否会漏，都要等商品说明或实测，页面里先不替它做保证。

### Listing points

- 420 ml 容量，面向通勤和办公饮用场景。
- 哑光白外观，画面和桌面搭配都比较干净。
- 翻盖结构；开合方式可见，密封表现仍需实测。
- 杯体尺寸、杯底直径和重量待补，补齐后再判断是否适配常见杯架。

## Douyin Ecommerce

2. 上班路上带的咖啡杯 420ml翻盖哑光白

### Buyer-facing copy

它的定位很简单：装一杯咖啡，带去上班。420 ml、哑光白、翻盖，没有把一堆还没验证的功能塞进标题里。

拍商品图时可以把开盖、合盖和手持比例讲清楚。至于会不会漏、能保温多久、能不能直接丢进洗碗机，先做测试再说。短视频里也不要用倒置不漏的镜头，除非现场真的按同样条件测过。

### Listing points

- 420 ml，适合一杯日常咖啡的通勤场景。
- 翻盖动作直观，适合用短镜头展示实际开合。
- 哑光白外观，商品卡缩略图中容易保持主体清楚。
- 所有性能词等实测，不用夸张对比和绝对化承诺。
