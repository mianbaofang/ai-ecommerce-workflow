# 花叔设计复评：20 秒 GitHub README 产品演示

## 基线评分

| 维度 | 现版 | 目标 | 判断 |
|---|---:|---:|---|
| 信息层级 | 7/10 | 9/10 | 每幕都有标题，但标题、卡片、说明长期等重，视线缺少明确落点。 |
| 构图变化 | 5/10 | 9/10 | 五幕反复使用左右分栏和白色面板，场景之间像换内容而不是换章节。 |
| 内容真实性 | 8/10 | 9/10 | 流程和限制真实，但真实来源截图没有进入画面，证据感仍靠模拟表格。 |
| 图像叙事 | 4/10 | 9/10 | 杯子在首尾反复出现，末幕又展示三个近似版本，掩盖了“研究、分类、审核、平台规格”的价值。 |
| 动效节奏 | 8/10 | 8/10 | 20 秒五幕清晰，每幕 4 秒可让 README 尺寸下的标题和证据留出阅读时间。 |
| 视觉辨识度 | 6/10 | 9/10 | 暖白、墨绿、朱红可保留，但固定网格、面板边框和大水印使用过量。 |
| 总体 | 6.3/10 | 8.8/10 | 动效已可用，主要返工应集中在内容构图和图像角色分配。 |

## 保留

- 20 秒、五幕、每幕 4 秒的叙事骨架。
- 暖白纸张、墨绿审核、朱红风险、黄色提示的编辑色系。
- “发现不等于读过”“官方类目字段优先”“自然化后仍要审核”三条边界。
- 单一暂停 GSAP 时间轴、可 seek、可重复渲染的 HyperFrames 结构。

## 修正

- 杯子只在第 1 幕作为用户输入出现一次；最终幕只显示一张缩略图，不再做三个杯子的接触表。
- 第 2 幕加入真实公开来源截图，让“证据”先被看见，再出现 Markdown 摘录。
- 第 3 幕使用无品牌充电器测试样品，建立“另一品类也能走通”的视觉证据，并明确标记为生成测试样品。
- 第 4 幕从两个并列白卡改为一张占主导的红线校样，突出审核动作。
- 第 5 幕改成一张生产交付墙：图片、平台尺寸、文案、审核状态是不同工件，不是四张同款平台卡。
- 网格只在第 1 幕轻微出现；后续依次使用来源裁片、分类路径、校样标记、生产装订线，形成场景差异。

## 一句话概念

一件商品从用户手里进入一张真实的“发布工作台”，证据、类目、文案和平台规格逐层盖章，最后变成可继续制作的交付包。

## 新版逐幕构图

1. **输入 / 桌面照片**：左侧大标题压缩到两行，三个输入方式变成贴在画面边缘的纸签；右侧只出现一次杯子，像用户刚放到桌上的产品。
2. **证据 / 研究剪报**：真实国内与跨境规格网页裁片前后叠放，Markdown 证据条横跨其上；画面不出现产品。
3. **分类 / 样品解剖**：无品牌 30W 单口 USB-C 充电器占左中，右侧用一条纵向分类路径和必要字段围住样品；明确写“生成测试样品”。
4. **审核 / 红线校样**：整张文案像编辑部校样纸，违规词被红笔圈划，右侧边栏给出事实、条件、待确认三项最小修订；不出现产品。
5. **交付 / 生产墙**：一张杯子缩略图、一张来源缩略图、一张尺寸规格单、一段自然文案和一个审核戳组成非对称拼贴；核心流程通过与图片逐张复核分开显示。
