# 商品文案发布前审核

本审核是核心 Skill 的内置能力，适用于标题、卖点、详情、FAQ、图片文字、口播和商品卡。它不依赖外部审核 Skill，也不承诺平台一定通过。

## 执行顺序

1. 从事实账本生成平台草稿。
2. 用内置规则或一个可选中文自然化 Skill 改写。
3. 回查数字、单位、SKU、材质、功能、兼容、认证、价格、赠品、物流和售后。
4. 读取 `references/compliance-terms.md`，检查风险词、完整语义、品类和目标平台。
5. 命中风险时给原句位置、风险原因、需要的证据和最小修订，不只输出一串词。
6. 修订后从第 3 步重跑，直到通过或明确缺少证据。

## 五层审核

| 层 | 检查内容 | 失败处理 |
|---|---|---|
| 事实 | 文案是否超出 `已确认` 商品事实 | 删除、改成条件句或放入 `待确认` |
| 词与语义 | 绝对化、排名、功效、安全、认证、稀缺、价格、结果保证 | 结合上下文判断，给最小修订 |
| 品类 | 食品、美妆、母婴、医疗相关、电子、汽配等专属限制 | 要求许可 / 测试 / 警示或暂不输出 |
| 平台 | 标题、属性、SKU、图片文字、口播和详情是否一致 | 按当前平台 / 叶子类目修订 |
| 目标市场 | 语言、币种、单位、消费者政策和监管表述 | 标记地区并在正式上架前复核 |

## 可选外部复核

- `yuwen-publish-precheck`：只在已安装且目标是其支持的国内内容平台时，用于最终公开文字的语义风险复核；不把它当成淘宝、京东、拼多多或跨境 Listing 审核器。
- `media-publish-check`：只在已安装且用户要审核实际短视频、封面、字幕、口播或直播素材时使用。
- 外部审核给出修订稿后，必须重新执行事实回归和本文件审核；不自动安装，也不写入核心依赖。

## 输出格式

| 位置 | 原句 | 风险类型 | 依据 / 缺失证据 | 最小修订 | 状态 |
|---|---|---|---|---|---|

结论只使用：

- `可作为上架草案`：当前检查未发现阻断项，仍需按当前后台复核；
- `修改后复核`：已有可修复问题，修订稿还要重跑；
- `缺证据，暂不输出`：功效、认证、兼容、价格、服务或资质无法支持。
