# 快速上手

## 这个 Skill 做什么

它从商品描述、公开商品链接或产品图片开始，先研究公开市场上的相似商品和页面观察价格，再按用户选择的平台生成文案和图片规格。

默认不会强制用户填写商品档案，也不会默认跑旧版 15 项长报告。

## 最简单的调用

```text
【跑公开电商市场研究】
产品描述 / 公开商品链接 / 产品图片:
目标平台(可选):
地区与语言(可选):
需要平台文案和图片规格吗:否
```

用户也可以直接发送一句话、一个公开链接或一张产品图。

更自然的三种说法都能触发：

```text
帮我看看这款便携咖啡杯在公开市场上的同类、页面价格和常见差评。
```

```text
研究这个公开商品链接，先给我一页结论：https://example.com/product
```

```text
根据我上传的产品图找相似商品；图片看不出来的材质和性能不要猜。
```

Agent 接到输入后直接开始。只有识别不出商品时才先问一个问题；目标平台等到需要文案和图片规格时再确认。

## 首次搜索能力询问

Skill 会用一句非阻塞提示询问以后是否配置可选的公开搜索 provider，同时优先用当前已有能力开始：

- 使用宿主已有的公开搜索；
- `anysearch` / `multi-search-engine`；
- `Tavily` / `Brave Search`；
- `agent-reach`；
- 宿主支持时的 `agentkey` 路由。

这是用户选择，不是安装前置。Skill 不自动安装 provider，也不要求用户把 API key 发到对话里。

## 搜索结果怎样变成结论

Agent 先把候选链接、搜索词、观察时间、页面状态、价格口径和可引用摘录整理为 Markdown 证据账本，再写一页结论。

- AnySearch 等工具已经返回 Markdown 时直接规范化。
- 用户给的是公开 HTML / URL，且宿主已装 `huashu-md-html`、`autocli` 或等价读取工具时，只转换最终引用的单页。
- 转换能力不可用时保留搜索摘要并标记 `仅发现`，不把它冒充已读全文。
- 有项目输出目录时可保存 `research-evidence.md`；纯对话任务则把精简证据表直接交付，不强迫用户先选路径。

## 默认输出

1. 商品识别摘要和搜索词方向。
2. 5-8 个相似商品链接和相似原因。
3. 公开页面观察价格区间。
4. 公开卖点、用户讨论中的痛点和机会点。
5. 最大风险与待人工确认项。

每个价格都说明平台、地区、观察时间、币种和口径。页面观察价不等于成交价，搜索结果靠前不等于稳定自然排名。

## 平台素材包

用户选择平台后，Skill 可以继续输出：

- 3 个标题版本；
- 3-5 条核心卖点；
- 商品描述；
- 5 个 FAQ；
- 关键词和禁用词提醒；
- 图片尺寸、数量、构图和安全区清单。

淘宝 / 天猫、京东、拼多多、抖音和快手会先使用当前叶子类目 / 具体商品类目及官方必填属性。开源数据集只能辅助判断候选类目，不能覆盖平台规则，也不能替商品补属性值。

## 自然文案

默认文案已经禁止套话、空泛总结和未经证实的“品质感”。若宿主已安装 `anti-ai-tone`、`renhua` 或 `humanizer-zh`，用户可选择增加一轮中文改写；改写后还要重新核对数字、规格、材质、功能、限制和平台字段，避免去 AI 味时改变商品事实。

## 发布前文案审核

自然化之后再跑内置审核，不是只扫一串词：

1. 检查事实和 SKU / 属性 / 图片文字是否一致。
2. 结合完整句子检查绝对化、排名、功效、安全、认证、价格、稀缺和售后承诺。
3. 检查品类限制、目标平台和目标地区。
4. 给出原句位置、风险、缺失证据、最小改法和 `可作为上架草案 / 修改后复核 / 缺证据，暂不输出`。
5. 修订稿重新跑事实与风险审核，不承诺“100% 过审”。

若宿主已安装，抖音等其支持的国内内容平台可以再调用 `yuwen-publish-precheck`；实际短视频、封面、字幕或直播素材可选 `media-publish-check`。它们不替代商品 Listing 的内置审核，也不自动安装。

## 生图分支

用户需要图片时，必须先确认模型/工具、用途、参考图权利、比例、尺寸、张数和交付方式。

优先从真实产品图派生不同平台尺寸，保持产品结构、颜色、Logo、包装文字和材质一致。没有生图工具时只输出素材 brief 和 prompt。

## 搜索与法律边界

默认只使用公开搜索结果和用户提供的公开资料。不做批量抓取、登录态读取、代理轮换、反爬绕过或自动发布。需要真实成交价、后台销量、关键词量或授权数据时，用户必须提供截图、导出或授权 API。

## 安装入口

自动发现和显式安装都使用 `skills/ai-ecommerce-workflow/SKILL.md`。旧的根目录和 `skill/` 路径不再是 Skill 入口；`skill/` 中留下的示例和评测笔记仅供历史参考。
