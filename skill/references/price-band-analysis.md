# 页面观察价格分析

价格分析只使用带来源、地区、币种、时间和口径的公开观察值。公开标价、活动价、SKU 可见价和搜索摘要不得写成真实成交价。

默认流程：

1. 选择 5-8 个相似商品候选，说明相似点和不可比因素。
2. 记录平台、市场、币种、读取时间、运费、优惠和 SKU 口径。
3. 只在样本可比时给页面观察区间；不同容量、材质、地区或套装要分开。
4. 把异常值和读取失败保留在证据账本，不用模型常识补价格。
5. 默认不计算建议售价、毛利、投流预算、CPC、ROAS 或止损线。

建议售价需要用户另行提供成本、物流、佣金、税费、退货和授权经营数据。详细规则见 `../../../references/public-search-policy.md` 和 `../../../references/research-evidence-ledger.md`。
