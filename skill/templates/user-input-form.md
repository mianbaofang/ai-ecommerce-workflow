# 可选输入示例

> 这不是必填表。直接给商品描述、公开链接或产品图片中的任意一种，就可以开始公开市场研究。

## 最简调用

```text
这是一个 420 ml 的便携咖啡杯，帮我查公开同类、页面观察价格和可打开的链接。
```

## 可选补充

```text
商品描述或公开链接:
产品图片: 已附 / 无
销售地区和语言(可选):
已知规格或包装信息(可选):
目标平台(做上架素材时再填):
需要的内容(可选): 公开研究 / 平台文案 / 图片规格 / 生图
```

缺少目标平台时，Skill 先交付通用公开市场结论。只有商品无法识别，或缺失字段会造成误购、合规风险时，才追问少量聚焦问题。

需要生图时再补充模型或工具、用途、参考图权利、比例、尺寸、数量、文字政策和交付方式。Skill 不自动安装工具，也不要求把 API key 发到对话里。
