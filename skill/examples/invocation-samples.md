# 当前调用样例

## 1. 只有描述

```text
这是一个便携咖啡杯，帮我查公开同类、页面观察价格和链接。
```

先返回一页结论、5-8 个候选链接、价格口径、机会和不确定项，不要求用户先填商品档案。

## 2. 公开商品链接

```text
研究这个公开商品页，并搜索相似产品：https://example.com/product
```

只读取用户提供或最终引用的公开单页。链接打不开时保留 `读取失败`，继续使用描述、图片和搜索摘要，不假装读过正文。

## 3. 只有产品图片

```text
根据这张产品图识别商品，再查公开同类。
```

外观只能标为 `图片可见`；材质、容量、性能、认证和功效没有证据时保持 `待确认`。

## 4. 需要平台素材

```text
研究完成后，给我淘宝和抖音的文案与图片规格。
```

确认目标平台和当前类目后，输出标题、卖点、描述、FAQ、关键词、风险提醒和图片要求。中国平台优先使用当前叶子类目和官方必填属性。

## 5. 需要生图

```text
按淘宝和 Etsy 的用途准备图片，并在我确认模型后生成。
```

生成前确认工具、参考图权利、尺寸、比例、数量和文字政策。所有平台版本从同一份已确认产品视觉源派生，并逐张检查产品保真和平台要求。

批量抓取、登录态访问、绕过验证码、自动发布、虚假评论和排名保证不属于本 Skill。
